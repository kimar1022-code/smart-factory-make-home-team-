## 9/5 진행 — 베이스 자세 측정 완성 + 랙 중앙 추종 파지 (미완: 기둥↔벽점 정렬)

### 오늘 확정된 것
| 항목 | 실측 |
|---|---|
| 베이스 자세 측정(기둥 색점 4점) | 벽 0~4개 전 조건 게이트 통과 (yaw σ 0.006~0.018°, 위치 σ 0.036~0.070mm) |
| 화면→로봇 매핑 | 직교 오차 0.0°, 30mm 이동을 30.0mm 로 판독 |
| 슬롯 목표 계산 정확도 | **가로축 0.02~0.15mm · rz 0°** (길이축은 파지 위치에 의존) |
| 랙 중앙 추종 파지 | 벽 17.7mm 이동 추종 파지 실증 |
| 안착 판정(80mm) | 밑판 뎁스 −80mm 기준으로 정정 후 정상 |

### 진범 3건 (전부 "잘 되는 것처럼 보이는데 틀린" 종류)
1. **`cam_server` 원본 버퍼 오염** — 오버레이를 RealSense 재활용 버퍼에 직접 그려, 다음 프레임 검출 입력에 지난 그림이 섞임(/raw 30회 중 7회). **검출기가 자기가 그린 점을 다시 검출** → 몇 주간의 유령점 유력 진범. `img = img.copy()` 로 수정, 오염 0/30.
2. **노출이 플리커 비안전값** — 120Hz 조명에서 프레임마다 검출 2/4↔4/4. 플리커 안전값(83·167·250·333·417)만 쓰도록 + `health_gate` 적응 노출.
3. **taught 랙 파지가 벽 길이방향 ~9mm 중앙 이탈** — 파랑 8.57mm·빨강긴 9.01mm(가로축은 0.04~0.15mm 정확). 삽입 시 벽이 편중되어 슬립.

### 🔴 다음 세션 1순위 — 기둥점 ↔ 벽점 정렬 보정
랙의 "색점 두 끝 중간"은 점이 대칭이 아니면 **벽의 물리적 중앙이 아니다**(실측 ~9mm 차이). 근본 해법은 **호버에서 든 벽 점과 기둥 점을 같은 화면에서 맞추는 것** — 그리퍼가 벽 어디를 물었든 무관해진다.

- 절차: 정렬 자세에서 [벽점↔기둥점] 관계를 성공 상태로 1회 저장 → 매 사이클 Δ 로 XY·rz 보정 후 하강
