# 조립식 주택 자동화 공장 — 하모니(2조) 로봇셀 프로젝트

조립식 주택을 로봇(FR5 협동로봇 + ZeKeep ×2 + 터틀봇)이 **사람 개입 0**으로 조립하는 데모 프로젝트의
상황 공유·인수인계용 저장소입니다.

- [`docs/2026-09-04_재설계_답변_베이스yaw보정_벽파지.md`](docs/2026-09-04_재설계_답변_베이스yaw보정_벽파지.md)

| 경로 | 내용 |
