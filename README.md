## 지금 문제 → 재설계 방향

1. **red_s(짧은 빨강)**: 작고 느슨해 파지 3mm 변동 + 기둥 진입 후 **양 카메라 벽점 소실** → 위 카메라론 불가.
2. **베이스 이동**: ZK 흡착이 밑판을 돌리면 기둥(끼우는 자리)도 이동 → 책상 마커론 못 따라감.
3. **9/4 카메라 마운트 교체** → 골든 전량 무효.

**재설계**(`docs/재설계_베이스이동_벽삽입_0904.md`): 기준계를 **밑판 외곽선+기둥(형상, 매 사이클 재검출)**으로 → 베이스 이동 자동 흡수. **측면 카메라**로 삽입 감시(기둥 진입 후 벽 밑동 vs 얹힘 판정). 골든 = "밑판 기준 슬롯 자리"(로봇 자세는 매번 계산).

## 안전 규칙 (사고 기반, 위반 금지) ⚠️

- **기둥 꼭대기 아래 XY 횡보정 금지** (챔퍼 없어 벽 슬립 — 사고 1건).
- **|ΔJ6|>180° 이동 금지** (±175 못 넘어 320° 회전 → controller_dead). J6=0 경유 자세 삽입.
- **관절 한계** J1·J4·J5·J6 ±175° / J3 ±160°. 넘기면 MoveIt −26으로 전 이동 거부.
- **동결 복구**: ServoJ 알람14 → `fr5_rescue.sh`(ResetAllError). controller_dead(앱 사망) → 전원급.
- **부품 랙 복귀는 사람이** (로봇 자동복귀 금지, 상태만 보고).
- **실기 가동 중 같은 DDS 도메인 테스트 금지** (도메인 99 격리).
