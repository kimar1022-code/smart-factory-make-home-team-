## 1. 프로젝트 개요

- **팀/데모**: 2조 "하모니". 조립식 주택을 로봇이 **사람 개입 0**으로 조립하는 데모.
- **로봇**: FR5(파이노 6축 협동로봇, 조립 담당) + ZeKeep(ZKBOT) ×2(반송/흡착) + 터틀봇(자재 운반).
- **마감**: 9/7(월) 최종. 주간 게이트 — 8/24 파지+삽입1건 / 8/31 P0 6개 풀시퀀스 / 9/4 코드프리즈 → 9/7 무개입 3연속.
- **역할**: 김애리 = FR5 조립(벽 파지·삽입) + ZK 반송 + 전체 통합. 비전은 별도(협의로 역할경계 확정).
- **집(HOUSE)**: 밑판(검정 3D출력, 210×140×86mm) + 기둥 4개(모서리, 검정, 꼭대기에 색점 마커) + 벽 4~5개(색별).

### 벽 색·종류 (중요 — 재질이 검출에 영향)
| 색 | 종류 | 길이 | 재질 | 슬롯(로봇좌표) |
|---|---|---|---|---|
| 파랑 | 문벽(긴벽) | 198mm | **흰 벽** | x170, rz180 (Y방향) |
| 빨강 | 창문 긴벽 | 198mm | **검정 벽** | x297, rz180 |

## 2. 지금까지 이룬 것 (9/1~9/3 = 최고 성과)

**9/3까지 파랑·노랑·빨강(긴벽) 3벽을 무보정(Δ≤0.5mm)으로 반복 삽입 성공.** red_s만 미완.

### 성공 방식 (마운트 교체 전 기준 — 지금은 골든 무효)
- **앞끝우선 place 러너**(place_front_first.py): 손목캠(앞끝, cam1) XY 먼저 맞추고, 새카메라(뒤끝, cam2)로 yaw.
- **홈포즈 골든**(사용자 설계, 결정타): 손으로 안착시키지 말고 **로봇이 집은 채 홈포즈(rx180/ry0/rz90or180)로 XYZ 조그 안착** 후 골든 캡처 → 파지 편차 0.05mm → 무보정 Δ0 삽입.
- **앵커 2종**:
  - **마커(ArUco, 책상)**: 유령점 없고 깨끗하지만 **책상 고정이라 베이스 이동 못 봄**. 조명 무관.
  - **dots(기둥 색점)**: 베이스와 한 몸이라 **베이스 이동 추종**. 파랑은 dots로 밑판 4.2° 회전 상태서도 삽입 성공. 단 유령점·프레임 소실 취약.
- **자코비안 실측**: 그 자세에서 로봇 X/Y 0.6mm 찔러 픽셀변화 측정 → −A⁻¹·해로 이동(축 매핑 발산 방지).
- **최소 실행 이동량**: 로봇은 자세마다 최소 실행치가 다름(0.6~1.15mm). 그보다 작은 명령은 버려짐 → move_xy_eff가 키워서 재전송+실제 이동량 반환.

### 핵심 발견(트러블슈팅) 요약
- 8/30: **진범=티칭한 손목 rx/ry 버리고 관측자세 것 물려받아 벽 밑동 2mm 이탈**(빨강 6연속 실패 원인). 그리퍼 교체(최대개도 원래 50).
- 9/1: 골든 정렬 시스템·**로봇 최소 실행 이동량이 자세마다 다름** 규명.
- 9/2: **ArUco 앵커 전환**·기둥 파손 사고(무정지 하강+예외경로 미정지)·앞끝우선 러너 완성.
- 9/3: **3색 풀사이클 성공**. 오후 **밑판 외곽선(형상) 앵커 개발 착수**(마커는 책상이라 베이스 이동 못 봄을 실측으로 확인) — edge_place.py·base_depth_corner.py.

## 4. 재설계 방향 (9/4 확정 — `~/Downloads/재설계_베이스이동_벽삽입_0904.md` 전문)

- **3층 좌표계**: [월드/로봇]—[베이스 프레임(밑판 외곽선+기둥, 매 사이클 재검출)]—[슬롯(STL 홈 오프셋)] / [그리퍼]—[벽 아래변 선(파지 골든)].
- 정렬 = 호버에서 **벽 아래변 선을 슬롯 홈 중심선에 맞춤**(둘 다 베이스 프레임 기준 → 베이스 이동 소거).

- **철칙**: 골든·벽·티칭 사용자 승인 없이 변경 금지. 미검증 분기는 실기 투입 전 사용자에게 먼저 말할 것.
