# 9/4 — 마운트 교체 + 베이스이동 재설계 (로봇은 비전용, 나는 로봇 안 쓰는 작업)

## 상황 전환
- **오늘 카메라 마운트 교체 → 골든(픽·플레이스) 전량 무효.** 재티칭은 로봇 자유로울 때.
- 사용자 지시: 오늘 로봇은 비전이 시키는 곳으로 이동(비전 도움). 나는 **로봇 안 움직이는 큰 작업**만.
- **목표 재정의: 베이스(밑판·기둥)가 움직여 끼우는 기둥이 같이 움직여도 벽을 꽂는다.** 측면 카메라(오늘 C270 부착)도 활용.

## 완료(로봇 이동 없음)
1. **하모니 콘솔(bf2_robot_console.html) 통합** (백업 .0904_bak):
   - 측면캠(C270 :8771) 플로팅 패널 신설(글로벌캠 자리 대체, tg-scam).
   - **글로벌캠(:8767) 영구 제거** — 패널·토글·워치독·시작점검·CSS 전부.
   - 벽 꽂기 플레이어(:8770)를 **리코더 패널**에 [열기] iframe으로(사용자 제안). 세션 없이 색버튼 삽입.
   - :8000 정적서버는 캐시 헤더 없어 **하드 새로고침(Ctrl+Shift+R) 필요**.
2. **재설계 문서**: `~/Downloads/재설계_베이스이동_벽삽입_0904.md`. 3층 좌표계(월드—베이스프레임—슬롯 / 그리퍼—벽선), 형상 기준계가 베이스이동 흡수, 측면캠 삽입감시, 골든 재정의(밑판 기준 슬롯 자리·로봇자세는 매번 계산).
3. **J6 대회전 봉인 가드**(bridge_server.py, `J6_SWING_MAX=180`): FR5 move 에서 |ΔJ6|>180° 거부(422). `allow_j6_swing:true` 로 강제. **코드만 반영, 다음 브리지 재기동 때 활성**(오늘 비전 방해 안 하려 재기동 미룸).
4. **카메라 자동복구 데몬**(tools/cam_autostart.sh, start_console.sh 등록): D435(8766) USB 꽂히면 자동 기동+밝기100 / 새카메라(8768) 죽음·얼음(프레임 3회 동일) 자동 재기동. **by-id 경로**로 USB 재열거 대응(C270·Realtek 둘 다 시리얼 200901010001 충돌 회피).
5. **자세별 회전 뎁스 뷰어**(tools/depth_view_rot.py :8772): rot_poses.json 트리거(check_front 90°·check_right/left 180°·그외 0°). **컬러 영상** 회전(검출 원본 무관). 측면캠 스트림 tools/side_cam.py :8771(/health 추가).
6. **측면 삽입감시 스캐폴드**(tools/side_slot.py): base_top_line·wall_bottom_y·seating(안착/얹힘). **ROI·문턱은 삽입 중 프레임으로 튜닝 필요**(구조만 완성).

## ★오늘 규명: J6 스윙 = controller_dead 진범
- 사용자 체크루틴(8자세) 재생 중 **동결(controller_dead, 전원급 심각)**. 사용자 "도달 불가 자세 없다"가 맞음 — **자세는 다 한계 안, 전환이 문제**.
- 진범: poseB(J6=+161.6°) ↔ check_left(J6=−159.0°). 물리적으론 손목 40° 차인데 **J6 ±175 못 넘어 반대로 320° 회전** → controller_dead. (231°/321° 스윙이 킬러, 152° 이하는 안전)
- 해법: ①자세 J6 오름차순 재배열(최대 스윙 321→152°) ②큰 전환 사이 J6=0 경유 자세 삽입 ③속도↓. + 위 J6 가드.
- 관절 한계도 실증: 드래그티칭으로 J1 176.7°·J4 −218° 넘기면 MoveIt −26(계획실패) 전부 거부 → 손으로 한계 안으로 되돌린 뒤 **fr5_rescue(ResetAllError)로 알람 해제**(전원 불필요, 자동 복구된 케이스도 있음).

## red_s 종일 실패 (교훈)
- 오픈루프 픽(픽 자세로 내려가 그냥 잡기)은 **파지가 매번 3mm씩 변동**(작고 느슨한 랙) — 어떤 땐 cam2/양캠 벽점 소실.
- 골든픽을 **잡은 채** 티칭했던 게 문제(잡으면 턱에 ~18mm 끌림 → 잡기전 랙위치와 18mm 어긋나 픽 정렬 실패). ungrasped 재티칭해도 위 사다리 0점(작아서).
- 삽입 사각: 기둥 진입 후 **양 캠 다 red_s 벽점 소실**(프레임 가장자리). z-정체 감시로는 "그리퍼서 얹힘"을 못 잡음(로봇 z는 계속 내려가니 통과) → z351 도달을 성공 오판했으나 실제 실패.
- **결론: red_s 는 측면 카메라 없이는 위 카메라로 신뢰 불가.** 지시서 v2·오늘 재설계 방향이 정답.
