## A. 기준계 — 형상 기반 base_frame (확정 채택)

### A1. 검출 파이프라인 (실증된 순서 그대로 코드화)
```
1) D435 뎁스: RANSAC 바닥평면 → 높이 마스크로 밑판 분리 (거친 탐색 전용)
2) 컬러: 밑판 minAreaRect → 서브픽셀 네 변 → 꼭짓점 (0.1px, 재현 ±0.05px·±0.03°)
3) 기둥: 밑판 꼭짓점 기준 바깥 대각 검정 막대 끝 + 흰 점 보조 (4/4, ≤4px)
4) STL 홈 오프셋 합성 (긴변 10/5.5, 짧은변 10/4.5mm) → 홈 중심선 (190.0/120.0mm 재현 확인)
```
- **뎁스의 역할은 ①번뿐** — 기둥·검정면 뎁스 사용 금지 (절반 무효 실측)
- ICP·6D 포즈 도입 금지 — 2D 기하로 충분하다는 현장 결론 유지

### A2. ArUco → 폴백으로 강등
- 인쇄된 마커 4장(ID 40-43)은 보관: 형상 검출이 대비·조명 조건에서 실패할 때의 보험 + 교차검증용
- 코드에는 형상 기반 실패 시 폴백 훅만 남기고 기본 OFF
- **단일 소형 마커로 각도 측정 금지** — 0.05°는 300px 이상 직선 또는 원거리 2점에서만 나옴 (실측)

### A3. 보조 마킹
- 색점 대신 **흰 점** 채택 (조명 무관, 검정 꼭짓점 탐색 보조 — 실측 우위)

## B. 벽 측정 — 컬러 외곽선 기반

### B1. 대비 규칙 (하드 제약)
| 부품 | 측정 배경 |
|---|---|
| 흰 벽 | 검정 밑판 위 구간 |
| 검정 벽 | 흰 책상 배경 구간 |
- ROI 선택 로직에 클래스별 배경 규칙 내장. 조건 불충족 시 측정 스킵 + 재촬영 자세로

### B2. 에지 검출
- 흰 벽 아래변: 그림자 띠 구간 → 고정 문턱 금지, **기울기(gradient) 최대점** 검출 사용
- fitLine 대상 300px 이상 확보가 각도 정밀 전제 — 확보 불가 시 각도 신뢰도 저하 플래그

### B3. yaw 보정 로직 (v1 원칙 유지, 파라미터 재실측)
- 데드밴드·게인(0.6)·5프레임 평균 유지
- σ 재실측 필요: 측정 소스가 스티커 2점 → 외곽선으로 바뀌었으므로 v1의 σ≈1° 가정 폐기, E1 재실행
- **J6 이중실행 금지 가드**: 동일 보정의 중복 적용 방지 (현장 언급 — 정확한 발생 조건은 원문 손상, 확인 필요)

### B4. J6 드리프트 대응 (실증 방식 채택)
- J6 왕복 시 TCP 0.3~0.9mm 드리프트 (자세 의존, 손목 60~165° 스윙 구간)
- **1.3mm 오버슈트 후 되돌기** 방식 실증됨 → 러너 표준 동작으로 코드화
- 드리프트량 로깅: 자세별 편차 축적 (후속 보상 테이블 후보)

## C. 삽입 시퀀스 — 단계형 서보잉

### C1. 단계 구조 (현 러너 구조 유지 + 명문화)
```
z478 (호버)  : 손목캠이 두 기둥 꼭대기 + 밑판 가장자리 동시 관찰 → 전체 측정
z443→388     : 앞 기둥=손목캠 / 뒤 기둥=신규캠 분담 관찰 → 접촉 판정
각 단계      : ΔX/ΔY/ΔYaw 산출 → 보정 → 재촬영 → 수렴 시 다음 단계
최종         : 저속 수직 삽입
```

### C2. 하드 제약 (사고 기반 — 위반 금지)
- 🔴 **기둥 꼭대기 아래에서 XY 횡보정 금지** — 리드인 챔퍼 부재로 벽이 홈 벽에 밀려 그리퍼 슬립 (사고 1건). XY 보정은 반드시 기둥 꼭대기 상방에서 완료
- 코드 가드: 현재 z < 기둥 꼭대기 z 이면 XY 보정 명령 거부 + 경고 로그

### C3. 다음 통합 작업 (팀원 계획과 정렬)
- "벽 아래변 선 vs 홈 중심선" ΔX/ΔY/ΔYaw 산출 단계를 러너에 통합 — 부품 준비 완료 상태
- v1의 진입 체크(걸림 판정) 개념은 접촉 판정에 흡수된 것으로 보임 — 러너의 접촉 판정 로직 명세 확인 후 중복 제거

## E. 계측·잔여 작업

- **E1(재실행)**: 새 외곽선 방식으로 클래스별 정지 반복 yaw σ 측정 → 데드밴드 재확정
- **E2**: 접촉 판정 문턱 — 정상/걸림 각 5회 분포 (v1 유지, 두 캠 분담 구조에서)
- **E3**: 사이클 로깅 v1 유지 + J6 드리프트량·보정 이력 추가
- 노랑 벽 실행 미완 → 파랑 성공 파라미터로 재현 시도
- 파랑 성공 로그(6.0→0.33mm) 보존 — 포트폴리오 정량 근거
