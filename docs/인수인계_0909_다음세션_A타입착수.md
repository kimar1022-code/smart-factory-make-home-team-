## 3. 버튼 절차 (콘솔 :8776)

### 3-1. 벽 한 장 (B타입 검증된 순서 — 픽 → 플레이스 순서는 물리적 강제)
1. [사용자] 랙에 벽 꽂기(가운데! 끝으로 치우치면 끝점 잘려 재관측·파지 밀림 → 오늘 red_in +2.38mm 사고)
2. `▶ 사이클(1→2→2')` → 파지 편차 ⏸ 뜨면 값 보고 [▶계속]/[⛔중단]
3. `WAIT DESCEND` 에서 화면 x·y·yaw 확인 → `⬇ 하강(3)` (**사용자만**)
4. 로그에서 `── DONE` 확인 후에만 "성공" 보고. red_s·red_in 은 안착 판정 `unknown` 이 정상(기둥 가림) → 눈으로 확인 부탁
5. 실패 시 `⛔ 중단` → 벽은 사용자가 처리. 재파지가 답인 경우가 대부분(정렬 5.5mm 초과 = 파지 문제)

### 3-2. 기준 재티칭 (오늘 red_s 로 확정된 순서, 4분 안에 3종)
1. [사용자] 벽 물고 손으로 안착 → `슬롯 기준 1/2` (로봇 안 움직임)
2. 벽 문 채 **z_seat+85(색별 정렬 높이)로 수직 상승** → `z440 기준 저장(손목)` (+ 그 색 ALIGN_ROLES 에 있는 다른 캠)
3. 수직 하강 안착 → 그리퍼 열기(rack_ref grip_open) → +30mm → `슬롯 기준 2/2`(관측자세로 가서 베이스와 짝맞춤)
- 셋을 **같은 조명·같은 베이스 자세**에서. 기준 expo 가 현재 노출과 다르면 `check()` 가 기준 expo 로 맞춘다(그래서 기준을 밤에 찍으면 낮에도 그 노출).

### 3-3. 출하 리프트 (오늘 신설 버튼 `🏠 리프트(출하)`)
- 전제: 집에 포크 손잡이 끼워짐, 출하지 (−700,−100) 비어 있음, 로봇 **빈손·z≥400**(게이트: 그리퍼<20 거부, z<400 거부)
- 절차(`fork_carry.carry`): 손잡이 위 (105,−420,440) → 파란 점 XY 보정(**부호 −(Ji·Δpx)**, 오늘 증명) → z280 파지 47(실측 49~50) → [속도10] z550→rz90→x−400→y−100→x−700→z285 → 개방(출하지 5mm 안에서만) → z575 → **홈 `fork.json home_tcp` (102.75,−496.36,578.36) — 관측자세 아님**

## 6. A타입 계획 — 다음 세션 1순위

### 6-0. 사용자가 알려준 A타입 사양
- 랙·벽은 B타입과 **같음**(같은 랙, 같은 벽). 벽 기준(rack_ref·grasp_sig)은 재사용 가능
- **베이스 스티커 위치는 같은데 색이 전부 흰색** → 지금 베이스 자세 측정(`find_base_4pts` = 좌상노랑·우상빨강·좌하파랑·우하파랑 순환)이 **꼭짓점 식별을 못 함** → 사용자: "아로커마커랑 다시 측정해야" 
- **내벽 2장, 두께 다름** → 새 키 2개(예: `red_in_a1`, `red_in_a2`), 그리퍼 닫힘값 각각, 내벽 전용 경로(`JAM_FREE`·`INNER_WALL_MODE`) 그대로 적용
- **노랑 ↔ red_s 슬롯 위치 서로 바뀜** → slot_ref·hover_ref 는 A타입용으로 새로 (rack_ref 는 그대로)

### 6-1. 순서 (반드시 이 순서)
1. **기준 분리부터**(안 하면 A 티칭이 B 를 덮어씀). 되돌리기 전 판(`git show ccd610f:tools/house_cycle.py`)에 `house_type`/`switch_house` + `state/house_a`·`house_b`·`shared` 심링크 구조가 있었다 — **사용자 승인 받고** 그 방식으로 다시, 또는 더 단순히 `STATE` 경로를 인자로(`house_cycle.py --state state/house_a`). 분리 후 **B타입 1색 사이클로 안 깨졌는지 확인.**
2. **흰 점 베이스 검출**: 색으로 꼭짓점을 못 가르니 (a) ArUco 4개(30/35/36/37)로 베이스 자세를 잡고 흰 점 4개는 위치로만 대응, 또는 (b) 흰 점 1개를 색점/큰 점으로 바꿔 달라고 사용자에게 요청(가장 싸다). `BDC`(뎁스 사각형)는 색 무관이라 그대로 씀. 검출기는 **A타입용 함수를 옆에 새로**(B 경로 불변).
3. 벽별 티칭 §3-2 순서 그대로: yellow(새 자리) → red_s(새 자리) → 내벽 a1 → 내벽 a2. 외벽 4 → 내벽 순서 유지.
4. 각 벽 사이클 1회 → `DONE` 확인 → 다음 벽.
5. 다 들어가면 리프트 버튼으로 출하(실기 첫 검증).

### 6-2. 하지 말 것
- B타입 파일(`state/house/`)을 A 값으로 덮어쓰기
- 흰 점을 억지로 색 범위에 넣어 B 검출기 고치기(B 경로 불변)
- 내벽 두께 차이를 하나의 키로 뭉개기
