# 재설계 — 베이스가 움직여도 벽을 꽂는다 (2026-09-04)

> 배경: 오늘 카메라 마운트 교체 → 골든 전부 무효. 목표를 **"베이스(밑판·기둥)가 움직여도 벽 삽입"** 으로 못박고,
> 로봇을 안 쓰는 설계·검출 코드를 오늘 완성한다. 재티칭(로봇 이동)은 로봇이 자유로울 때.
> 원칙(지시서 v2): 실측이 제안을 이긴다. ArUco·고정 골든 위치 의존 → 형상 기반 + 측면 카메라로 대체.

---

## 0. 왜 지금까지 베이스 이동에 약했나 (실측 정리)

| 앵커 | 베이스 이동 추종 | 문제 |
|---|---|---|
| ArUco(책상) | ✗ 못 봄 | 마커가 책상 고정 → 베이스 돌면 기준이 안 따라감 |
| 색점(기둥) | ○ 따라감 | 유령점·프레임 가장자리 소실·짧은 벽 캠 사각 |
| **형상(밑판 외곽선+기둥)** | **◎ 따라감** | 검출만 견고하면 베이스와 한 몸 → 이동 자동 흡수 |

핵심: **기준계를 "베이스에 붙은 것"으로 잡으면 베이스 이동은 자동으로 상쇄된다.**
밑판 외곽선·기둥은 베이스와 한 몸이라, 매 사이클 다시 검출하면 움직인 위치를 그대로 따라간다.
→ 골든은 "밑판 기준 자리"로만 저장하면 되고, 절대 로봇 좌표에 박제하지 않는다.

---

## 1. 좌표계 3층 (재설계 핵심)

```
[월드/로봇] ── 고정 ── [베이스 프레임] ── STL ── [슬롯(홈 중심선)]
                         ↑ 매 사이클 재검출(밑판 외곽선+기둥)      ↑ 부품 도면(불변)
[그리퍼 프레임] ── 파지 골든 ── [벽 아래변/탭 선]
```

- **베이스 프레임**: 밑판 외곽선(서브픽셀 네 변) + 기둥 꼭대기 4점. 매 사이클 손목캠으로 재검출. 베이스가 움직이면 이 프레임이 통째로 따라감.
- **슬롯(홈 중심선)**: 베이스 프레임 + STL 홈 오프셋(긴변 홈↔홈 190 / 짧은변 120, 판 쪽 5.5/4.5mm)으로 계산. 검출 불필요, 기하로 나옴.
- **벽 선**: 그리퍼에 물린 벽의 아래변·탭을 컬러 서브픽셀로. 파지 골든(벽이 그리퍼에 어떻게 물렸나)만 티칭.
- **정렬**: 호버에서 `벽 아래변 선` 을 `슬롯 홈 중심선` 에 맞춘다 → ΔX·ΔY·ΔYaw. 둘 다 베이스 프레임 기준이라 **베이스 이동은 식에서 소거**.

이 구조에서 "골든 플레이스 = 로봇 자세"가 아니라 **"골든 = 밑판 기준 슬롯 자리"**. 로봇은 매번 그 자리로 이동을 새로 계산.

## 2. 검출 파이프라인 (로봇 없이 오늘 개발·검증)

카메라는 라이브라 **로봇 이동 없이** 프레임을 받아 검출기를 만들 수 있다. 마운트가 바뀌었으니 파라미터는 새 프레임으로 재실측.

### 2A. 손목캠 — 베이스 프레임
1. 뎁스 RANSAC 바닥평면 → 밑판 높이대역 마스크(거친 분리 전용, 지시서 D: 뎁스는 이 1단계만).
2. 컬러: 밑판 `minAreaRect` → 네 변 서브픽셀(2패스, Huber) → 꼭짓점. (기존 `base_depth_corner.py`·`edge_place.py` 재사용, 새 마운트로 σ 재측정)
3. 기둥 꼭대기: 밑판 꼭짓점 바깥 대각 검정 막대 끝 + **흰 점 보조**(조명 무관). 4/4 ≤4px.
4. STL 홈 오프셋 합성 → 홈 중심선(긴변 190 / 짧은변 120mm).

### 2B. 손목캠 — 인핸드 벽 측정 (지시서 B)
- 흰 벽 아래변: **검정 밑판 위 구간**에서만(대비 규칙). 그림자 띠 → 고정문턱 금지, **기울기 최대점**.
- 검정 벽 아래변: **흰 책상 배경 구간**에서.
- fitLine 300px↑ 확보 시 각도 신뢰, 아니면 신뢰도 저하 플래그.

### 2C. 측면 카메라 — 삽입 감시(신규, red_s 사각·저기둥 구간 해결)
- 손목캠은 기둥 진입(z437↓) 후 벽점을 잃는다(양 캠 모두). **측면캠은 옆에서 벽 밑동과 기둥 슬롯을 계속 본다.**
- 역할 ①: 하강 중 벽 밑동이 슬롯에 **들어가는지 vs 기둥에 얹히는지** 실시간 판정(z-정체 감시가 못 잡던 "그리퍼 안에서 밀림"을 옆에서 직접 봄).
- 역할 ②: 안착 확인 — 벽 밑동이 밑판 높이까지 내려갔는지.
- 역할 ③(선택): 호버 단계에서 벽↔슬롯 수평 간격 보조 측정(손목캠과 교차검증).
- 측면캠은 책상 고정이라 베이스가 움직이면 슬롯도 옮겨 보이므로, **슬롯 위치를 측면캠에서도 형상으로 재검출**(밑판 윗선·기둥 옆선).

### 2D. 폴백
- 형상 검출이 대비·조명으로 실패 → ArUco(ID 40-43) 폴백 훅(기본 OFF, 지시서 A2).
- 벽 아래변 300px 미확보 → 각도는 흰 점/기둥 기하로 보조.

## 3. 삽입 시퀀스 (단계형 서보잉 + 측면 감시)

```
z478 호버 : 손목캠으로 [베이스 프레임 + 슬롯선] 재검출 + [벽 아래변] 측정
            → ΔX/ΔY/ΔYaw (전부 베이스 프레임 기준 = 베이스 이동 소거)
            → J6(yaw)·XY 보정, 수렴까지 (기둥 위, 안전)
z443     : 재측정·미세보정. 여기까지 XY 완료 (지시서 C2: 기둥 꼭대기 아래 XY 금지)
z437↓    : XY 보정 금지. 손목캠 벽점 소실 → 측면캠으로 전환
            측면캠으로 하강 감시(들어감/얹힘 판정) — 얹히면 즉시 정지·상승
z_seat   : 측면캠으로 안착 확인 → 완료
```

- 하드 가드: `현재 z < 기둥 꼭대기 z` 면 XY 보정 명령 거부 + 경고(지시서 C2, 이미 러너에 있음).
- **J6 대회전 봉인 가드(신규)**: 이동이 J6를 ±175 못 넘어 반대로 크게(>180°) 돌아야 하면 J6=0 경유 분할 또는 거부. (오늘 controller_dead 원인 — 지시서 B3/손목 스윙 봉인의 실증 조건)

## 4. 골든의 재정의 (마운트 교체 대응)

| 골든 | 옛 방식(폐기) | 새 방식 |
|---|---|---|
| 플레이스 | 로봇 자세 + 마커 픽셀 박제 | **밑판 기준 슬롯 자리**(홈 중심선). 로봇 자세는 매번 계산 |
| 픽 | 잡은 뒤(post-grasp) 픽셀 | **잡기 전(랙) 벽 위치** + 파지 골든(어떻게 물리나) |
| 파지 | 유지 | 유지 — 벽이 그리퍼에 물린 상대 자세(20mm 상승 검증) |

→ 재티칭 시(로봇 자유로울 때) 이 정의로 다시 뜬다. 오늘은 검출기가 이 값을 뽑을 수 있게 준비.
