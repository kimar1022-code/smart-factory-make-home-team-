## 1. 🔴 A타입 손대기 전에 반드시 — 기준이 섞이면 B타입이 날아갑니다

지금 기준 파일이 **색 이름 하나로만** 구분됩니다.

```
rack_ref.json   slot_ref.json   grasp_sig.json   hover_ref.json   pose_refs/
   전부 키가 { blue, yellow, red, red_s, red_in }
```

**A타입에도 파랑 벽이 있으면, 그걸 티칭하는 순간 어제 잡은 B타입 파랑 기준을 덮어씁니다.**
어제 반나절 걸려 잡은 것이 한 번의 [저장] 으로 사라집니다. 내벽/외벽을 분리했던 것과 같은 이유입니다.

- [ ] **[나]** 기준 전체 백업 (`state/house` → `state/house.BACKUP_B타입_0909`)
- [ ] **[나]** 기준에 **집 타입 구분** 추가 — 두 가지 방식 중 선택
      - (a) 키를 `houseB/blue` 처럼 바꾸기 — 파일 구조 변경, 코드 수정 범위 큼
      - (b) **집 타입별 state 디렉터리 분리**(`state/house_b/`, `state/house_a/`) — 코드 변경 최소, 권장
- [ ] **[나]** 분리 후 **B타입 한 색으로 사이클 1회** — 분리 작업이 B타입을 안 깼는지 확인
- [ ] **[사용자]** 확인: 그 사이클이 어제와 같은 정확도로 들어가는지

> 합격 기준: B타입 기준 파일이 A타입 티칭에 절대 노출되지 않을 것 + B타입 1색 사이클 정상

## 2. A타입에 대해 제가 모르는 것 — 답해주셔야 진행됩니다

A타입은 제가 실물을 본 적이 없습니다. 아래를 알려주시면 티칭 계획을 짜겠습니다.

- [ ] **[사용자]** **벽 구성** — 몇 장이고 어떤 종류입니까? (외벽 4 + 지붕? 내벽 있습니까? 창문·문 별도입니까?)
- [ ] **[사용자]** **색점 스티커** — A타입 벽에도 색점이 붙어 있습니까? B타입과 같은 색 체계입니까?
      (지금 검출기는 파랑 `H 95~115` · 노랑 · 빨강 두 구간으로 고정돼 있습니다)
- [ ] **[사용자]** **밑판 기둥 색점** — 지금 베이스 자세 측정은 꼭짓점 4개가
      **좌상 노랑 · 우상 빨강 · 좌하 파랑 · 우하 파랑** 순환일 것을 기대합니다.
      A타입 밑판이 다르면 `find_base_4pts` 를 A타입용으로 따로 만들어야 합니다
- [ ] **[사용자]** **밑판 크기·기둥 높이** 가 B타입과 다릅니까? (다르면 안착 z 와 하강 구간이 달라집니다)
- [ ] **[사용자]** **랙** — B타입과 같은 랙을 씁니까, 별도 랙입니까? 벽 세우는 방향은 같습니까?
- [ ] **[사용자]** **벽 두께** — 그리퍼 닫힘값이 달라집니다 (B타입: 외벽 7~13, 내벽 6, 포크 47)

> 이 중 **기둥 색점 배치**와 **랙 위치**가 가장 큽니다. 둘이 B타입과 같으면 티칭만 하면 되고,
> 다르면 검출기를 A타입용으로 하나 더 만들어야 합니다.

## 3. A타입 티칭 — 벽 한 장당 순서 (B타입에서 확립된 절차 그대로)

**픽 → 플레이스 순서는 물리적으로 강제입니다.** 파지 높이가 안착 깊이를 바꾸므로 픽을 먼저 확정해야 합니다.

벽 한 장당:

1. [사용자] 랙에 벽을 꽂고, 조그로 **파지점까지 이동** → 좌표 알려주기
2. [나] `rack_ref` 저장 (Pc0↔Tg0 짝 · ang0 · z_pick · 그리퍼값 · 노출)
3. [사용자] 그 자리에서 파지 → [나] **파지 서명 저장** (★랙 위에서 문 상태에서만)
4. [사용자] 손으로 슬롯에 안착시킨 뒤 → [나] `slot_ref` 1/2 저장
5. [사용자] 벽 빼고 관측자세로 → [나] `slot_ref` 2/2 (베이스 페어링)
6. [나] z440 호버 기준 촬영 → [로봇] 사이클 1회 → 안착 성공 시 기준 자동 승격

- [ ] **[나]** A타입 벽 목록 확정 후 위 절차를 벽 수만큼 반복

> ★어제 배운 것 두 가지를 지킵니다
> - **기준을 1회 측정으로 저장하지 않습니다** — 파랑을 1회로 저장했다가 1.15mm 틀렸습니다(5회 산포는 0.03px)
> - **서명은 랙 위에서 문 상태에서만** — 픽 자세(열림)나 z440 에서 찍으면 상수 편차가 박힙니다
